# example-experiment

Kurz: Beispielprojekt, erzeugt von der Sandbox‑Automatik als Demo.

Quickstart

```bash
# 1) (optional) Virtuelle Umgebung erstellen
python -m venv .venv
.venv/bin/pip install -r requirements.txt

# 2) Smoke‑Test
python main.py --smoke
```

Hinweis: Dies ist ein Beispiel, kein Produktivcode. Keine Secrets enthalten.
