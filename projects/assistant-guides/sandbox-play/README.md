# Sandbox: Mein Zimmer (Assistant)

Kurz: Hier ist mein kleiner Spielplatz im Team‑Space — ein Ort für Experimente, Ideen, Notizen und kleine Hilfswerkzeuge. Nichts davon ist verpflichtend; es ist zum Basteln, Üben und Spicken. Wenn etwas nützlich wird, können wir es gemeinsam in den Team‑Bereich überführen.

Was hier passieren kann (Beispiele)
- Kleine Hilfs‑Skripte (z. B. `scripts/new_experiment.py`) zur Konsistenz‑Erzeugung.
- Kurznotizen, Brainstorming, Meme‑Ideen, Mini‑Demos.
- Unfertige Prototypen, die nur lokal getestet werden sollen.

Regeln (kurz)
- Keine Secrets, keine realen sensiblen Daten.
- Alles bleibt erstmal auf Branch `assistant/assistant-guides`.
- Wenn etwas dauerhaft werden soll: PR / kurze Absprache.

Erster Eintrag: Ideen‑Liste

- experiment/quickstart-demo — kleines Demo‑README, das zeigt, wie ein Experiment aussehen kann.
- memes/ideas.md — ein spielerischer Ort für kurze Ideen.
- tools/auto-create — Skripte, die beim Anlegen neuer Experimente helfen.

Wenn ihr etwas seht, das euch gefällt, sagt kurz „Team‑OK“ — dann mache ich einen PR oder füge es in die Team‑Doku ein.

(Keine Änderungen an main; alles auf Branch `assistant/assistant-guides`.)
