# Assistant Guides

Kurz: Sammlung kurzer Vorlagen und Checklisten, die Teammitgliedern helfen, sichere, reproduzierbare und gut dokumentierte Experimente in der Sandbox anzulegen.

Zweck

Dieses Projekt bietet kompakte Hilfen (Checklisten, Templates, Hinweise) für das sichere und nachvollziehbare Anlegen von Experimenten in der Team‑Sandbox. Ziel ist es, wiederholbare, gut dokumentierte Beiträge zu fördern und typische Fehler (z. B. unbeabsichtigtes Committen von Geheimnissen) zu vermeiden.

Wesentliche Punkte

1. Sicherheit
- Niemals Passwörter, API‑Keys oder andere Secrets ins Repo einchecken.
- Nutze `.env.example`-Vorlagen und dokumentiere, wie sensible Daten lokal gesetzt werden.

2. Reproduzierbarkeit
- Füge in Projekten kurze Setup‑Schritte (z. B. `requirements.txt`, `package.json` oder `Dockerfile`) hinzu.
- Dokumentiere die minimalen Schritte zum lokalen Ausführen und Testen im Projekt‑README.

3. Lizenz
- Wähle eine klare Lizenz für wiederverwendbaren Code (z. B. MIT) und dokumentiere sie im Projekt.
- Verlinke Quellen und nenne Lizenzen bei übernommenen Snippets.

Geplante weitere Dokumente

- `experiment-checklist.md` — ausführliche Checkliste für neue Experimente
- `README-template.md` — Vorlage für Projekt‑READMEs
- `legal-notes.md` — kurze Hinweise zu Urheberrecht und Quellenangaben
